# 30-Day Military Workout Timer

A single-file, GitHub Pages-ready web app based on the supplied 30-Day Military-Style Home Workout schedule.

## Features
- Days 1–30
- Daily exercise list
- Adjustable work seconds
- Adjustable rest seconds
- Adjustable rounds
- Start, pause, reset
- Automatic work/rest/exercise/round progression
- Recovery days, AMRAP days, and Day 30 fitness test displayed
- Settings saved locally in the browser
- Mobile-friendly
- No server, database, framework, or external dependency

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` and this `README.md`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.

GitHub will publish the site at `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`.

## Workout source
The exercise schedule and default intervals are taken from the supplied 30-day workout PDF.
